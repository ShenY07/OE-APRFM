# Micro–macro random-feature baseline

`constraints/`, `modules/`, `geometry/`, and `utils/` contain the implementation. `run_1d.py`, `run_2d.py`, and `periodic.py` contain the experiment solvers and command-line interfaces.

Run `PYTHONPATH=src:. python3 -m baselines.mm_oerfm.run_1d --help` or `python3 -m baselines.mm_oerfm.run_2d --help`. Attribution is preserved in [ATTRIBUTION.md](ATTRIBUTION.md).
