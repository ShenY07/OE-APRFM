# Numerical experiment plan

## P2 数值参考解说明

P2 的数值参考解由原输运方程 SI-DSA sweep 生成。正式误差计算采用空间网格
\(N_x=1024\)、全速度网格 \(N_v=512\)，速度区间为 \([-1,1]\)，使用均匀
梯形求积；正、负速度各占 256 个离散点。迭代停止容差为 \(10^{-11}\)，最大
迭代次数为 16384，DSA 松弛系数为 \(10^{-2}\)。

内部网格加密检查使用 \((N_x,N_v)=(512,256)\) 与
\((1024,512)\)。该检查只用于确认参考解离散误差低于 OERFM 误差，不作为
独立数值实验或正文结果表。当前内部检查数据如下。

| \(\varepsilon\) | 正式分辨率 | SI-DSA 迭代数 | 最终迭代差 | 加密前后 \(f\) 相对差 | 加密前后 \(\rho\) 相对差 |
|---:|---:|---:|---:|---:|---:|
| \(1\) | \(1024\times512\) | 19 | \(4.171\times10^{-12}\) | \(4.410\times10^{-3}\) | \(1.248\times10^{-4}\) |
| \(10^{-3}\) | \(1024\times512\) | 1257 | \(9.779\times10^{-12}\) | \(1.176\times10^{-5}\) | \(1.148\times10^{-5}\) |

参考解生成时间不计入任何待比较方法的运行时间。

## 内部实验主线

| 编号 | 影响因素 | 控制变量 | 扫描变量 | 主要问题 | 输出 |
|---|---|---|---|---|---|
| I1 | \(\varepsilon\) 全尺度稳定性 | 最终选定的 \(J\)、配点、分区和 `rcond` | \(\varepsilon\) | P1–P5 | \(E_f,E_\rho\)、条件数、数值秩、时间 |
| I2 | 特征数 \(J\) | 配点、分区、`rcond`、种子 | 每区特征数 \(J\) | P1、P3 | \(E_f,E_\rho\)、参数量、时间 |
| I3 | 配点数或超定比 | 特征数、分区、`rcond`、种子 | 配点数、方程数/未知数 | P1、P3 | \(E_f,E_\rho\)、超定比、条件数、时间 |
| I4 | 固定预算下的区域分解 | 总特征数、总未知数、配点协议、种子 | 空间区域数 | P1、P3 | \(E_f,E_\rho\)、条件数、数值秩、时间 |
| I5 | `rcond` 与数值秩 | 特征数、配点、分区、种子 | SVD 截断 `rcond` | P1、P3 | \(E_f,E_\rho\)、有效秩、条件数 |
| I6 | 随机特征稳健性 | 所有超参数 | 种子 11、23、37、53、71 | P1–P5 | 中位数、最小值、最大值 |

### 统一内部实验规则

| 项目 | 规则 |
|---|---|
| 一维受控问题 | P1 |
| 二维受控问题 | P3 |
| 最终问题覆盖 | P1–P5，\(\varepsilon=1,10^{-3}\) |
| 误差网格 | 独立于训练配点的固定评估网格 |
| 区域分解预算 | 固定总特征数和总未知数；每区特征数随区域数调整 |
| 随机特征统计 | 5 个固定种子，中位数及 `[min,max]` |
| 计时 | 特征生成、系统组装、线性求解、总时间分别记录 |
| 线性代数 | 记录 `rcond`、有效数值秩及与求解一致的条件数 |
| 图像 | 参考解、数值解、绝对误差分别输出；二维问题同时输出平面图和三维图 |

## 外部方法比较

| 方法 | 状态 | 形式 | 对比要求 |
|---|---|---|---|
| OE-APRFM | 已有当前结果 | odd-even 随机特征 | 使用最终选定内部参数 |
| MM-APRFM | 基模代码已接入 | micro-macro 随机特征 | 匹配物理问题、预算、配点、种子和评估网格 |
| RFM | 待建立统一运行入口 | 原始方程随机特征 | 匹配预算、配点、种子和评估网格 |
| OE-APNN | P1–P5 三种子已导入评估 | odd-even 神经网络 | P5 方孔制造解版与异质介质版分开报告 |
| SI-DSA | P2 两个尺度已有 | 原输运方程 sweep + DSA | 报告离散规模、迭代容差、迭代数、收敛状态和时间 |
| OE-SI-DSA | 待新增正式结果 | odd-even 方程迭代 + DSA | 与 SI-DSA 使用相同网格、求积、容差和迭代上限 |

### 外部比较输出

| 类别 | 指标或内容 |
|---|---|
| 精度对比 | 有解析解问题的 \(E_f\)、\(E_\rho\)；P2 相对 parity-SI 参考解的误差 |
| 时间对比 | 统一硬件上的训练/组装、求解及总时间；参考解生成时间单列且不计入方法时间 |
| 参数对比 | 特征数、网络参数数、线性未知数、配点数、离散自由度 |
| 条件数对比 | 线性方法的条件数、`rcond` 和有效秩；不适用方法记为 `N/A` |
| 实验结果对比 | 参考解、方法解、误差分布、二维平面图和三维图 |

外部比较只使用各方法完成内部参数选择后的冻结配置。调参过程不与最终方法结果
混入同一张表。
