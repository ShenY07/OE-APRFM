# P7：周期扰动的输运—扩散演化

本页为旧试运行配置。最新要求已独立编号为 [E6](e6_periodic_transport.md)，采用256系数、4288行和解析初始右端；本页数据不计入E6的20条预设轨迹。

本配置替代P7原入流驱动时空拟合任务；旧脚本和数据仅保留为历史，不覆盖。本轮只增加这一个一维含时算例。

方程为 `epsilon² f_t + epsilon v f_x = rho-f`，域 x∈(0,1)、v∈[-1,1]、t∈[0,0.2]。sigma_s=1、sigma_a=Q=0；空间周期边界；初值 `1+0.2 cos(2πx)`。

上述为预设单seed试验配置，不承诺其足以解析所有尺度，也不把周期最小二乘约束称为精确满足。

## 时间推进与参考

记P为角平均，后向Euler的三个OE残差为：

1. `(P r_new-P r_old)/dt + <v j_new,x>`；
2. `epsilon²[(I-P)(r_new-r_old)/dt+(I-P)(v j_new,x)] +(I-P)r_new`；
3. `epsilon²(j_new-j_old)/dt+v r_new,x+j_new`。

独立参考利用唯一空间Fourier模态，求角离散复振幅的连续时间矩阵指数；全角Gauss128/256加密，不使用RF或RF时间推进生成参考。参考角加密不等于连续角域严格认证。

连续扩散对照：`1+0.2 exp(-4π²t/3) cos(2πx)`。
离散扩散对照：`1+0.2(1+4π²dt/3)^(-n) cos(2πx)`。两者分别报告，不把dt平台称为AP退化。

## 交付量

- Ef、Erho、q=<v j>的绝对/相对误差；真流为零时相对误差留空。
- 余弦振幅 `2∫(rho-1)cos(2πx)dx` 及参考振幅，避免背景1掩盖动态误差。
- 连续/离散扩散差异；质量漂移相对于数值初始质量，并单列数值初始质量。
- 初始q=0与非零Fick流不相容，保留t=0与后续松弛结果，不事后移动评价起点。
