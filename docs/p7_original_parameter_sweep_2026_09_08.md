# P7 原方法参数约定下的单分区扫描

本轮 12 组已完成；没有配置达到 Ef、Eρ 同时不超过 1e-3 的目标。
仅 seed=11，结果是参数筛查，不是三种子认证。未修改冻结表。

## 固定约定与对齐范围

固定方程、初边值、奇偶投影结构、t∈[0,.1]，参数仅扫描每场特征数 J、随机尺度和内部时空配点数。
使用单个时空速度分区；t/x 以中心和半宽归一化，速度特征坐标为 2v−1，负速度通过奇偶化处理。
随机参数采用原一维实现的 [0,scale) 分布，r/j 共享内层参数。
本轮 NumPy 使用 seed=11 的嵌套特征池，不是原 Flax 初始化的逐位复现；原 RandomFeatureSpaceXV 还固定内部 seedXV=42。
因此这是对齐分布和构造约定的含时参数筛查，不能称为原代码的逐位复现。

损失固定为单位 L2 行归一化后所有行直接求和，宏观行按角度配点重复，与原稳态默认计数一致。
保持初值 512 点、每侧边界 256 点，训练使用 16 个正角度节点，SVD 截断为 1e-12。
参数扫描中增加内部点数会改变其相对于固定初边值行的总权重；这是行求和协议的固有行为，不能解释为纯采样加密。

为什么本轮只扫单分区：原一维 continuous_1d_odd_even.py 的导数组装使用 psi_b，
而 function_space.py/solution_construction.py 的评估路径使用 psi_a。
单分区归一化后这些 PoU 在所考察区域内均为 1，避免该多分区路径差异混入本轮扫描。
该多分区问题需要独立修复和验证后，才能把分区数作为可靠扫描参数；本轮未修改原稳态实现。

## 结论

- eps=1 最好组为 J=512、scale=1、2048 时空点：Ef=0.66618、Eρ=0.51883。
  独立初值 RMS=0.10868、左入流 RMS=0.08174；条件数约 2.97e9，1024/1024 满秩。
- eps=.001 最好组为 J=256、scale=.5、1024 时空点：Ef=0.016831、Eρ=0.016743。
  独立初值 RMS=0.11071、左入流 RMS=0.10085；原始全谱条件数约 2.13e12，SVD 保留 509/512 维。
  此处条件数包含被截断的奇异值，不能称为有效条件数。
- 两组在 t=.05 也未达标；不能仅选择最后时刻宣称目标完成。
- 仅加大 J 或调整随机尺度未将本算例推进到 1e-3。小 ε 的最佳误差仍约为阈值的 17 倍。
- 本轮出现更高条件数及少量丢秩，之前低预算下的 QR/SVD 结论不能无条件外推到这些新矩阵。
- 初边值误差仍大，且行求和下内部点加密增加了 PDE 的相对总权重。下一轮应明确固定损失下的采样协议，
  优先核对初边值配点数及原多分区组装/评估一致性；不以新特征结构替代原方法。

参考仍为 256 空间单元/16 正角度/800 步。eps=1 参考 Ef 加密差异约 8.42%，
本身也不足以认证 1e-3；目前远大于该差异的求解误差不能归结为参考误差。
