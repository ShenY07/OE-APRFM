# P7 分步检查：制造解、局部空间与配点（2026-09-08）

## 检查范围

本轮完成制造解链路检查，以及 14 组 seed=11 的局部空间/配点/预算诊断。
没有改变 PDE、初边值物理定义或损失权重，没有替换冻结结果。
局部特征为新试验空间，不是已通过的最终方案。

## 第一步：制造解检查

为检查同一矩阵组装与求解链路，注入能够精确表示下面多项式的固定基：

```
r = 1 + x^3 + 2tx + 6 eps^2 x (v^2-1/3)
j = -3vx^2 - 2tv + eps^2 (4v-6v^3)
f = r + eps*j
```

它满足无源输运方程，且 r_t=2x、j_t=-2v 均非零。初值和入流取解析迹。
在 eps=1、.01、.001 下，投影 OE 与未投影 OE 都通过 1e-9 解误差容差，
并检查了时间导数及奇部方程。这是可表示多项式的链路控制试验，不是随机特征对原入流问题达到该精度的证据。

新增 `feature_factory`、`boundary_data`、`initial_data` 注入接口，默认仍使用原随机特征和原数据。
`evaluate.parity_fields` 提供 r、r_t、r_x、j、j_t、j_x，供独立残差检查。
局部 PoU 的和为 1、导数和为 0、乘积与归一化导数、速度奇偶性均通过独立有限差分检查。
原有奇偶性、导数、参考扩散极限和守恒检查也通过。

## 第二步：固定预算局部空间

- global：原始全局特征。
- local_x：空间分区 [0,.05,.15,.4,1]，时间仍为 [0,.1]。
- local_tx：时间分区 [0,.02,.1]，空间分区 [0,.15,1]。
- 两种局部空间均为 4 块，将每场 J 个特征均分；使用固定的光滑紧支撑归一化 PoU，支撑半径为单元半宽的 1.75 倍。
- 所有局部系数仍为常数，一次全局最小二乘求解，不进行逐步时间推进。
- 预算 J 是每场特征数，总系数数为 2J。

独立检查使用 seed=1907 的 512 个时空点、16 个正角度节点（训练为 8 个），
以及 4096 个独立初边值点。PDE RMS 使用物理残差及角求积权重，不做矩阵行归一化。
参考解仍为 256 空间单元、16 正角度、800 步，eps=1 的参考认证限制沿用之前报告。
独立点有限，不能据此证明全域残差上界。

最明显的问题是 eps=.001、local_x、J=128、256 点时，宏观残差在训练点为 0.05925，
独立点为 66.076。这是明确的配点间失控；不能因为训练残差低或满秩就认为局部离散充分。
同空间加密到 1024 点后，独立宏观残差降至 0.2209，密度误差也从 41.45% 降至 9.42%。

固定 1024 点、每场 256 特征后，local_x 相比同预算 global：
- eps=1 密度误差由 61.95% 降至 21.62%，初值和左入流也改善，但奇部物理残差更大。
- eps=.001 密度误差由 1.21% 升至 5.77%，奇部 RMS 由 0.0302 升至 0.4951。
因此局部化改善了动力学区域的部分逼近，但当前形式没有同时保持小 eps 精度和方程残差。
local_tx 的首轮结果更差，加密后仍不合格，没有继续放大该方案。

## 判断与下一步

1. 可表示制造解没有暴露组装/导数/系数恢复错误。
2. 局部空间会引入新的采样分辨率要求；总行数很多、满秩，并不充分。
3. 局部化不是直接可用的修复：本次没有一个配置同时通过解、初边值和独立 PDE 残差改善要求。
4. 行归一化依赖特征矩阵，所以换空间也会改变实际物理损失度量。上述对照保持缩放规则相同，
   但不是严格的固定物理范数下最佳逼近比较；不能把全部差异只归因于空间。
5. J 改变时随机空间非嵌套，且本轮只有一个种子，不宣称收敛率或全尺度成功。

本轮候选未通过上述门槛，因此不扩大到三种子正式比较。
后续更值得检验的是保留全局宏观空间、增加局部补充，而非将全部特征换成局部空间；
或者显式分离 rho(t,x) 与速度相关部分，并同时检查奇部闭合残差。
这些仍是待验证方向，本轮未实现。
